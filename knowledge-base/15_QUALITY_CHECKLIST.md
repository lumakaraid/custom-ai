# QUALITY CHECKLIST
# Standards and Validation Criteria

Every piece of content must meet Lumakara's quality standards before being considered complete. This checklist ensures consistency, value, and brand alignment across all 1,080 contents.

---

## OVERALL QUALITY STANDARDS

### Content Must Be:
1. **Valuable:** Provides genuine insight or actionable advice
2. **Unique:** Not repetitive or template-like
3. **On-Brand:** Matches Lumakara voice and values
4. **Accurate:** Factually correct and well-researched
5. **Engaging:** Captures and holds attention
6. **Actionable:** Provides clear next steps
7. **Complete:** All required elements present
8. **Compliant:** Meets all technical requirements

---

## PRE-GENERATION CHECKLIST

Before generating content, confirm:

✅ **Context Loaded:**
- [ ] Content topic selected from library
- [ ] Target audience identified
- [ ] Content pillar assigned
- [ ] Special date considered (if applicable)
- [ ] Brand guidelines reviewed

✅ **Requirements Clear:**
- [ ] Character limits understood (80/250)
- [ ] Visual prompt requirements clear (slides 1,2,5)
- [ ] Visual keywords needed (all slides)
- [ ] Output format understood (PHP array)

## POST-GENERATION CHECKLIST

After generating content, verify:

✅ **Visual Keywords:**

- [ ] Comma-separated format
- [ ] Include Indonesian context

✅ **Social Media:**

✅ **Quality Metrics:**

## QUALITY SCORING GUIDE

### Quality Score (0-100)
**90-100:** Exceptional - Highly valuable, engaging, perfectly executed
**80-89:** Excellent - Strong value, good engagement, well-executed
**70-79:** Good - Solid value, decent engagement, properly executed
**60-69:** Acceptable - Basic value, some engagement, meets requirements
**Below 60:** Needs improvement - Regenerate

**Factors:**
- Content value and insights
- Engagement potential
- Clarity and structure
- Actionability
- Uniqueness

### Brand Relevance (0-100)
**90-100:** Perfect alignment with Lumakara brand
**80-89:** Strong alignment, minor adjustments possible
**70-79:** Good alignment, some elements could be stronger
**60-69:** Acceptable alignment, several elements need work
**Below 60:** Poor alignment - Regenerate

**Factors:**
- Brand voice consistency
- Service alignment
- Value proposition match
- Target audience fit
- Positioning clarity

### Viral Potential (0-100)
**90-100:** Highly shareable, strong hook, broad appeal
**80-89:** Very shareable, good hook, good appeal
**70-79:** Shareable, decent hook, some appeal
**60-69:** Somewhat shareable, weak hook, limited appeal
**Below 60:** Low shareability - Consider regenerating

**Factors:**
- Hook strength
- Relatability
- Emotional resonance
- Shareability
- Timeliness

### Estimated Engagement (0.0-15.0%)
**8.0-15.0%:** Exceptional engagement expected
**5.0-7.9%:** Strong engagement expected
**3.0-4.9%:** Good engagement expected
**1.5-2.9%:** Average engagement expected
**Below 1.5%:** Low engagement expected - Improve

**Factors:**
- Hook quality
- Content value
- Audience relevance
- CTA strength
- Visual appeal

## RED FLAGS (Immediate Regeneration Required)

❌ **Character Count Violations:**
- Any headline >80 characters
- Any body text >250 characters
- No exceptions

❌ **Missing Required Elements:**
- Missing visual prompts on slides 1, 2, 5
- Missing visual keywords on any slide
- Missing any required field

❌ **Brand Voice Violations:**
- Uses "Anda" instead of "kamu"
- Corporate jargon without explanation
- Overly formal or stiff tone
- Hype or overpromising

❌ **Content Quality Issues:**
- Generic or template-like content
- No actionable value
- Repetitive of other contents
- Factually incorrect

❌ **Structure Problems:**
- Illogical flow
- Missing key elements
- Weak hook or CTA
- Incomplete slides
