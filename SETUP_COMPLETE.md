## TROUBLESHOOTING

### Issue: Custom GPT Not Following Instructions
**Solution:** Remind it of the guidelines in your prompt:
"Please follow the system instructions and use the knowledge base files."

### Issue: Character Counts Exceeded
**Solution:** Ask Custom GPT to regenerate:
"The headline on slide 2 is too long. Please regenerate with ≤80 characters."

### Issue: Output Format Wrong
**Solution:** Reference the format file:
"Please output in the exact PHP array format specified in 13_PHP_OUTPUT_FORMAT.md"

### Issue: Content Too Generic
**Solution:** Ask for more specificity:
"This content feels generic. Please make it more specific with real examples and unique insights."
